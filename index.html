RLS via Tree Inheritance
can_read(a, b) :=
  b.path ⊆ a.path

// cpl-001 can read drg, eco, knn, spn
// spn-001 can only read spn
// Tree inheritance — no fixed role columns
Access control emerges from path containment, not role tables. A civilizational planner inherits read access to all nested levels. The sovereign person sees only their own leaf. Middleware checks path subset — no Postgres, no ACL tables, no vendor dependency.
